OCR & PDF check

Renders a page of known text, runs it through the real processing pipeline, recognises it with the vendored Tesseract, and builds a searchable PDF from the word boxes. This is the check to run if OCR misbehaves — it exercises vendor/ loading, the worker, and the PDF text layer. Takes 10–30 s on first run while the WASM core loads.
